# Paper branch

This branch contains the revised manuscript based on the frozen `P2-FROZEN-V1` candidate.

- `P2_revised_manuscript.md`: canonical text-source mirror of the revised manuscript.
- `PAPER_VALIDATION.json`: provenance, source/revised DOCX hashes, frozen-model binding, and final render QA status.
- `P2_FREEZE_VALIDATION.md`: defensive-validation evidence emitted by the frozen-model Action.

The separately generated revised DOCX is named `心源性猝死_P2模型修订稿.docx`; its SHA-256 is recorded in `PAPER_VALIDATION.json`. The user-provided original manuscript was not overwritten and its SHA-256 is also recorded so preservation can be checked independently.
